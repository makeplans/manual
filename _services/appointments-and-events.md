# Appointments and events: the difference

MakePlans has two kinds of reservation. Which one you need depends on who decides the time.

| | Appointment | Event |
|---|---|---|
| Who chooses the time | The customer, within your opening hours | You, when you create the event |
| Set up as | A **service** | An **event type** with **events** |
| How many can book | One customer per time by default | Many, up to a maximum number of attendants |
| Typical use | Consultation, haircut, massage, rental | Class, course, seminar |

## Appointments

An appointment is a reservation for one customer with a start and end time, such as a haircut from 13:00 to 13:45. Customers book inside the opening hours of the resource. Each time they can choose is called a slot.

By default one customer can book each slot. To allow more, raise the [capacity of the resource]({% link _availability/capacity.md %}).

## Events

An event has a fixed start and end time and is open to several customers. You set a maximum number of attendants so it cannot be overbooked. Customers sign up for a specific event, such as "Yoga" on 12 April from 19:00 to 20:30.

## Event types

An event type groups similar events into one list on the booking site, for example one event type "Yoga" and another "Pilates". The event type is not an event itself. Each event has its own date, time and maximum number of attendants.

You can use services and event types in the same account.
