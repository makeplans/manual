# Waitlist

With the waitlist on, a customer who finds a time or an event fully booked can join a waitlist instead of being turned away. They are told when a place opens.

## Turn on the waitlist for the whole account

1. Open setup and select **Booking site**, then **Rules**.
2. Tick **Enable waitlist for fully booked slots and events**.
3. Choose a **Waitlist promotion mode**:
   - **Auto-promote first in line**: when a place opens, the first customer on the waitlist gets it. This is the default.
   - **Notify all on waitlist**: everyone on the waitlist is told that a place has opened. The first to book gets it.
4. Optionally, enter a **Text for slots with waitlist**. It replaces the standard text shown on fully booked slots.
5. Select **Save**.

## Turn it on for one service or event type

Edit the service or event type and tick **Enable waitlist (overrides account setting)**.

## See who is waiting

- Waitlisted attendants are shown on the event page.
- In the **Agenda**, filter on the state **Waitlisted** to see all waitlisted reservations.
