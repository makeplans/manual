# How many resources do I need

Your subscription price depends on the number of resources, so it is worth getting this right. See the [pricing page](https://makeplans.com/en/pricing/) for current prices.

## Staff and things customers book

Create one resource for each person or thing that can be booked on its own.

- Each employee customers can book is one resource. Nobody is double booked, and customers see who they booked with.
- Each court, room or item you rent out is one resource.

If one resource can take several reservations at the same time, raise its capacity instead of creating more resources. See [Resource capacity]({% link _availability/capacity.md %}).

## Events and classes

- If events depend on a room, create one resource per room and select it on each event. MakePlans then keeps the room from being used twice at the same time.
- If the location does not matter, use one shared resource for all events. This costs less, but MakePlans cannot stop two events being placed in the same place at the same time.
