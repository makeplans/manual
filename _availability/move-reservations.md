# Move reservations between resources

When an employee leaves or a room is replaced, you can move everything from one resource to another in one step.

{% include alert.html type="warning" content="This moves all reservations and events for the resource, both past and future. Customers are not notified." %}

1. Open setup and select **Tools**.
2. Select **Migrate bookings between resources**.
3. Select the resource to move from in **From resource**.
4. Select the resource to move to in **To resource**.
5. Select **Migrate**.

To move a single reservation, open it, select **Edit** and choose another **Resource**.
