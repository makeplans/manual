# What is a resource

A resource is an employee, a room or an object. Every reservation belongs to one resource. Resources exist to prevent double bookings: once a resource is booked for a time, nobody else can book it for that time.

A resource has a title, opening hours, and a list of the services it offers. Customers can choose a resource when they book, or take the first one that is free.

## Examples

| Business | Resources | Services or event types |
|---|---|---|
| Hairdresser | Linda, John, Peter | Haircut (30 min), Haircut (60 min), Colouring (120 min) |
| Squash centre | Squash room red, Squash room blue | Squash (45 min) |
| Yoga studio | Yoga room big, Yoga room small | Hatha yoga, Bikram yoga (event types) |
| Tutoring | Class resource | Math tutoring (event type) |

## Resources for events

Each event is also placed on a resource. Use a resource for the room or venue if you need MakePlans to stop two events being placed in the same room at the same time. If the location does not matter, one shared resource for all events is enough.
