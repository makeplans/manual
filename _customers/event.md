# Sign up for an event or class

1. Open the booking site of the business and select the event or class.
2. You see the dates it runs, with time and price. Select the one you want.
3. Confirm who you are with the code you receive by email or SMS.
4. Check the details and complete the booking.

You sign up for one date at a time. To attend several dates of a class, sign up for each of them.

## If the event is full

Some businesses have a waitlist. If you join it, you are told when a place becomes free.
