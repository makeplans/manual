# Zapier integration

Zapier connects MakePlans to other apps. For example, a new reservation can add a row to a spreadsheet or create a task in another system.

## Connect

1. In MakePlans, open setup and select **Developer**, then **API**. Enable the API and copy the API key. See [Enable the API](/integrations/api/).
2. In Zapier, create a new Zap and search for [MakePlans](https://zapier.com/apps/makeplans/integrations).
3. When asked, enter your account's subdomain and paste the API key. The subdomain is the first part of your booking site address.

You can now use events in MakePlans as triggers in your Zaps.
