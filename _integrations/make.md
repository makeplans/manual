# Make integration

Make (formerly Integromat) connects MakePlans to other apps, in the same way as Zapier.

## Connect

1. In MakePlans, open setup and select **Developer**, then **API**. Enable the API and copy the API key. See [Enable the API](/integrations/api/).
2. In Make, search for MakePlans and create a new connection.
3. Enter your account's subdomain and paste the API key. The subdomain is the first part of your booking site address.

You can now use events in MakePlans as triggers in your scenarios.
