# Plausible Analytics

MakePlans can send visits on your booking site to your Plausible Analytics account.

## Set it up

1. In Plausible, add a website with the address of your booking site, for example `youraccount.makeplans.com`. If you use your own domain for the booking site, enter that instead.
2. In MakePlans, open setup and select **Booking site**, then **General**.
3. Tick **Enable Plausible Analytics** and select **Save**.
