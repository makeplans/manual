# Slack integration

With Slack connected, MakePlans posts a message in a Slack channel each time a new reservation is made.

## Connect Slack

1. Open setup and select **Integrations**, then **Slack**.
2. Select **Connect to service** and log in to Slack.
3. Choose the channel MakePlans should post to.
4. Back in MakePlans, choose the MakePlans account to connect.
