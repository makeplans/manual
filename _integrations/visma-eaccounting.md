# Visma eAccounting integration

With Visma eAccounting connected:

- A new customer in MakePlans is created in Visma eAccounting automatically.
- You can create an order in Visma eAccounting from a reservation in MakePlans.

## Connect Visma eAccounting

1. Open setup and select **Integrations**, then **Visma eAccounting**.
2. Select **Connect to service** and log in to Visma eAccounting. If you have several accounts, choose the one to connect.
3. Back in MakePlans, choose the MakePlans account to connect.

## Set it up

1. Set the payment terms for orders made from MakePlans.
2. Link each MakePlans service to a product in Visma eAccounting.
