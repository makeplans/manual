# Bento integration

With Bento connected, each new customer in MakePlans is added to Bento as a subscriber.

## Connect Bento

1. Open setup and select **Integrations**, then **Bento**.
2. Enter your **Site UUID**, **Publishable Key** and **Secret Key** from Bento.
3. Tick **Always opt-in** if every customer should be added as opted in.
4. Select **Save integration**.
