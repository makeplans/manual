# 24SevenOffice integration

With 24SevenOffice connected:

- A new customer in MakePlans is created in 24SevenOffice automatically.
- You can create an order in 24SevenOffice from a reservation in MakePlans.

## Connect 24SevenOffice

1. Open setup and select **Integrations**, then **24SevenOffice**.
2. Enter the **API-Username** and **API-Password** from 24SevenOffice.
3. Select **Save integration**.

## Set it up

1. Set the payment terms for orders made from MakePlans.
2. Link each MakePlans service to a product in 24SevenOffice.
