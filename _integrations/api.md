# Enable the API

MakePlans has a complete API. You need it for your own integrations and for services that connect with an API key, such as Zapier and Make.

1. Open setup and select **Developer**, then **API**.
2. Select **Do you want to enable the API?**
3. The API key is shown. Copy it to where it is needed.

{% include alert.html type="warning" content="The API key gives full access to your account. Share it only with people and services you trust." %}

## Give a developer access

Add the developer as a user on your account. See [Account and billing](/account/overview/). To use the JavaScript API from your own website, the website's domain must be approved under **Developer**, **Embed**. See [Embed in your website](/booking-site/embed/).

The API is documented at [developer.makeplans.com](https://developer.makeplans.com).
