# Fiken integration

With Fiken connected:

- A new customer in MakePlans is created in Fiken automatically.
- You can create an order in Fiken from a reservation in MakePlans.

## Connect Fiken

1. Open setup and select **Integrations**, then **Fiken**.
2. Select **Connect to service** and log in to Fiken.
3. Choose the Fiken account to connect.

## Set it up

1. Choose which bank account Fiken should use for orders made from MakePlans.
2. Link each MakePlans service to a product in Fiken.
