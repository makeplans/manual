# Calendar and display settings

Open setup and select **UX** to change how the admin looks and what things are called. Select **Save** when you are done.

## Calendar

| Setting | What it does |
|---|---|
| **Slot duration** | The size of each row in the calendar grid, in minutes. |
| **Slot label interval** | How often a time label is shown down the side of the calendar. |
| **Prevent event overlap** | Changes how reservations at the same time are drawn in the calendar. When ticked, they are shown side by side instead of on top of each other. It does not affect what can be booked. |
| **Hide weekends** | Shows Monday to Friday only. |
| **Display text for reservation in calendar** | Your own text on each reservation in the calendar, built from merge fields such as the customer's name. |

## Miscellaneous

| Setting | What it does |
|---|---|
| **Show link for reservations without status in agenda** | Adds a link in the agenda that lists the reservations with no attendance status set, so you can see which ones still need to be marked as checked in, completed or no show. |
| **Warn when a customer has this many no-shows** | Warns you about customers who have reached this number of no-shows. |

## Custom titles

If your business uses other words, enter them here. For example, call resources "Therapists" or event types "Classes". The new title replaces the standard one everywhere it is shown, both in the admin and on the booking site.

You can set your own title for resource, service, event type, product, gift card, add-on, subscription and pass.

## Your own appearance

The light or dark theme of the admin is personal. Select your initials in the top right corner, then **Profile**, **Edit**, and choose **Light**, **Dark** or **Auto (follow system)** under **Theme**.
