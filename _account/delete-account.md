# Delete your account

Deleting an account is permanent. The account and all its data are removed and cannot be brought back.

If you only want to stop paying for a while, [pause the account]({% link _account/pause-cancel.md %}) instead. A paused account costs nothing and keeps everything.

If you are leaving because something is missing, tell us first. MakePlans has many settings and an API, so there may already be a way to do what you need. If not, we would like to know.

## Before you delete

Export a copy of your data in setup under **Export**. See [Export and import data]({% link _account/export-import.md %}).

## Delete

You must be logged in as a user with full access.

1. Open setup and select **Account**.
2. At the bottom of the page, under **Delete account**, select **Yes, continue**.
3. Read the warning and select **Yes, please delete all my data.**
