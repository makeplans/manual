# Users and access levels

Give each person their own login. Users are free: you pay per resource, not per user. Sharing one login is a security risk and makes it impossible to see who did what.

## Add a user

1. Open setup and select **Users**, then **New user**.
2. Enter **Name** and **Email**.
3. Choose an **Access level**.
4. Select **Save user**.

{% include figure.html src="/assets/images/account/users/01-new-user.png" alt="The new user form with name, email and the access level Basic setup" %}

The new user receives an email with a link for choosing a password. If the email does not arrive, they can use the forgot password link on the login page.

One person can be a user on several accounts.

## Access levels

| Access level | Can do |
|---|---|
| **Only calendar** | Use the calendar and agenda, manage reservations and edit customers. No access to setup. |
| **Basic setup** | The same, and set up services, resources and categories. |
| **Full access** | Everything, including account settings, users, billing and deleting the account. |

All users see all reservations for all resources. The calendar can be filtered to one resource, but that is only a view. A user cannot be limited to one resource.

## Change or remove a user

Open setup and select **Users**. Select the pencil next to a user to change the access level, or **Delete** to remove them. Only a user with full access can do this. Support cannot change access levels for you.

## When someone leaves

- Remove their user straight away.
- Removing a user does not remove the resource. If the person was also bookable, edit or delete the resource too, so customers cannot book them.
- Look through the list now and then and remove users you do not recognise.

## A user is not a resource

A user is a login. A resource is something customers book. An employee who both logs in and takes reservations needs both.
