# Bug bounty and reporting a security issue

## The bug bounty program has ended

MakePlans no longer has a bug bounty program. We do not pay rewards for reports.

Over time the program brought in a large number of low-quality reports: output from automated scanners, templated or AI-written text, and issues that did not concern our systems. Handling them took time away from real security work.

We are grateful to the researchers who sent valid and careful reports while the program ran. Security remains a priority, and we keep investing in it in other ways.

## Report a security issue

If you have found a security issue in MakePlans, email [hello@makeplans.com](mailto:hello@makeplans.com). Describe what you found and how to reproduce it.
